# Concussion Guide

A dependency-free, responsive website prepared for GitHub Pages. Medical-facing copy and references come from the website sections of `source/Concussions (5).docx`. Drafting notes and research instructions found after the References section are intentionally excluded from the public website.

## Preview

Open `index.html`, or serve the folder with any basic local web server. No package installation or build step is required.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose the main branch and root folder, then save.

All paths are relative, so the site works from a project URL such as `https://username.github.io/concussion-guide/`.

## Content rule

`content.js` is the canonical website-content file. Preserve medical strings exactly unless the source DOCX is formally updated.
